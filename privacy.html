한끼채널 개인정보처리방침

시행일: 2026년 10월 28일

한 줄 요약
한끼채널은 회원가입이 없고, 개발자가 이용자의 개인정보를 수집하거나 서버로 전송하지 않아요. 설정과 기록은 이용자의 기기 안에만 저장돼요. 다만 앱 화면 아래에 구글 애드몹(AdMob) 광고가 표시되며, 이 과정에서 구글이 광고 식별자 등을 처리해요.

1. 수집하는 개인정보

개발자는 이름, 연락처, 이메일, 위치, 계정 정보 등 이용자를 알아볼 수 있는 정보를 수집하지 않아요. 앱에는 회원가입이나 로그인이 없고, 이용자 정보를 받는 개발자의 서버도 없어요.

2. 기기에 저장되는 정보

앱을 편하게 쓰도록 아래 내용이 이용자의 기기(브라우저 또는 앱 저장 공간)에만 저장돼요. 개발자에게 전송되지 않으며 개발자는 이 내용을 볼 수 없어요.

  • 즐겨찾기한 메뉴, 직접 추가한 메뉴
  • ‘못 먹는 것’ 설정
  • ‘결정’을 누른 메뉴 기록(최근 30개)과 최근에 뽑힌 메뉴
  • 뽑기 범위, 식당 찾기 지도, 소리 설정

3. 외부 서비스 이용

  • 글꼴: 화면 글꼴을 구글 폰트(Google Fonts)에서 내려받아요. 이 과정에서 이용자의 IP 주소 등 통상적인 접속 정보가 구글에 전달될 수 있고, 이는 구글의 개인정보처리방침을 따라요. 개발자는 이 정보를 받지 않아요.
  • 식당 찾기: ‘근처 식당 보기’를 누르면 이용자가 고른 지도 서비스(구글 지도, 네이버 지도, 카카오맵)가 열리고 메뉴 이름이 검색어로 전달돼요. 이후의 정보 처리는 해당 서비스의 방침을 따라요. 위치 권한 요청이 있다면 지도 서비스가 하는 것이고, 한끼채널은 이용자의 위치에 접근하지 않아요.
  • 공유·이미지 저장: 결과 공유와 이미지 저장은 기기의 공유 기능을 이용해요. 이용자가 무엇을 누구에게 공유했는지는 앱이 수집하지 않아요.
  • 광고(구글 애드몹): 앱 하단에 구글 애드몹 배너 광고가 표시돼요. 광고를 보여주고 성과를 측정하기 위해 구글이 기기의 광고 ID, IP 주소, 기기·앱 정보 등을 수집·이용할 수 있어요. 이 정보는 개발자가 받지 않으며 구글의 개인정보처리방침(https://policies.google.com/privacy)을 따라요. 기기 설정(설정 → 개인정보 보호 → 광고)에서 광고 ID를 삭제하거나 맞춤 광고를 끌 수 있어요.
  • 앱 제공 서버: 앱 파일을 내려받는 호스팅 서비스는 일반적인 접속 기록(IP 주소, 접속 시각 등)을 남길 수 있어요.

4. 사용하지 않는 것

개발자가 직접 운영하는 방문자 분석·추적 도구는 사용하지 않아요(위 구글 애드몹 광고 제외). 카메라, 마이크, 연락처, 위치 권한도 요청하지 않아요.

5. 보관과 삭제

기기에 저장된 내용은 이용자가 직접 지울 수 있어요. 앱의 ‘먹은 음식’ 창에서 ‘기록 지우기’, ‘내 메뉴’ 창에서 즐겨찾기와 추가한 메뉴 삭제를 쓰거나, 기기 설정에서 앱(또는 브라우저)의 저장 데이터를 삭제하면 모두 지워져요. 앱을 삭제해도 같이 지워져요.

6. 아동의 개인정보

한끼채널은 만 14세 미만 아동의 개인정보를 수집하지 않아요. 앱은 아동을 주 대상으로 하지 않아요.
